# 🎓 University Clearance System (ASTU)

A full-stack web system for managing student clearance across departments.

## 🚀 Features
- Student clearance request
- Department approval/rejection with comments
- Real-time status tracking
- Notification system
- Admin user & department management
- Clearance certificate generation (PDF)

## 🛠 Tech Stack
- Frontend: React
- Backend: PHP (REST API)
- Database: MySQL
